## 1. 核心循环

点击抛竿 → 咬钩时按住 → 按住收线、鱼冲刺（红色 !）时松手 → 钓上来拿金币和 Buff → 每片海钓满 4 条叫出海怪 → 打败海怪进下一片海 → 九片海打到龙宫的海龙王。

- 一局约 10～25 分钟（机器人 8～12 分钟，真人慢一倍左右）。
- 断光线可以从当前海域续关（送 1 层护盾）。
- 金币进钱包，回主页在商店买装备；鱼获进小馆做菜卖钱。

## 2. 现有系统（已实现）

| 系统 | 要点 |
|---|---|
| 九片海 | 阳光浅滩 → 彩虹珊瑚礁 → 冰封海湾 → 沉船墓场 → 熔岩热泉 → 无光深渊 → 失落遗迹 → 星光海 → 龙宫 |
| 鱼 | 36 种普通鱼 + 9 种稀有鱼；每种一个 Buff（收线、咬钩、金币、鱼线、放电、暴击、温顺、挣扎、护盾、狂收、闪光、回血），一局内叠加，有上限 |
| 海怪 | 9 只，每只一条特殊规则；海龙王三阶段 |
| 收集 | 闪光鱼（5 倍金币、双倍 Buff）、尺寸冠、特别花色、海边小礼物、图鉴 54 格（9 页海域 + 2 页稀有鱼） |
| 商店 | 帽子 / 鱼竿 / 船 / 花色，每件一个小加成；海况专属装备只能挣不能买 |
| 小馆 | 鱼获做菜自动卖，离线营业 8 小时；装修 37 件；人气、客人、鱼缸 |
| 平台 | 中 / 英 / 日 / 韩 / 西，云存档，排行榜（金币） |

### 2.1 海况（现行 10 级版，将被 §4 替换）

第一次打败海龙王后，新一局前可选海况 0～10。每级叠一条数值规则：鱼更有劲、咬钩要快、海怪更耐打、每片海多钓 1 条、少一颗心、鱼更狡猾、鱼线更脆、预警更短、鱼往回游更快、续关不送护盾。金币每级 +10%。海况 3 / 6 / 10 送浪花帽 / 风暴船 / 海神冠。搏斗超过 15 秒鱼会累。

**问题（用户反馈）**：难度偏低、每级只是数值变化没有特色；打完海况 1 就能下潜，下潜到一半回主页又想挑下一级海况，节奏被打散。

### 2.2 无尽深海（现行）

通关后「继续下潜」：第 10 层起按九片海循环，每层更强、金币更多。深海里生命最多 4 颗、护盾最多 1 层、放电麻痹减半、削弱鱼的 Buff 有下限、冲刺预警逐层缩短。不能续关。通关后回主页也能接着下潜，直到开新一局。

### 2.3 稀有鱼（已实现，未上线）

每片海 1 种，只在海况 3 以上或无尽深海出现，每次咬钩 7%。一条同时给两个 Buff，金币约为本片海最好鱼的 2.5 倍，鱼更难拉一点。小白鲸、麒麟鱼放生加人气，其余 7 种做成小馆新菜。

| 冰封海湾 | 小白鲸 | 双层护盾 + 挣扎超短（放生） |
| 沉船墓场 | 幽灵鱼 | 狂收更久 + 闪光更多 |
| 熔岩热泉 | 凤尾火鱼 | 生命 +1 + 放电更猛 |

## 4. 海况 2.0（讨论中，未实现）

### 4.1 已定

- 5 级，逐级叠加；每级一个有特色的**机制**，数值变化顺带放进去。
- 金币每级 +20%（顶级仍是 +100%）。
- 老存档折算：原海况 n → ⌈n / 2⌉（海况 10 → 5）。存档里加版本号，只折算一次；进行中的局（含续关检查点）一起折算。
- 专属装备改到海况 2 / 4 / 5 送（浪花帽 / 风暴船 / 海神冠）。
- 稀有鱼从海况 3 开始出现（或无尽深海）。
- 通关海况 5 → 无尽深海开放（D10）。

### 4.2 设计约束

- 不晃屏，不能让画面变暗到看不清鱼、浮漂和张力条（用户担心「夜海」会让画面更暗）。
- 每个机制都要有清楚的提示和应对方法，看得懂就能躲。
- 不拿宝物也能过（D12）；新手级机器人允许死几次但要能通关。
- 不改普通 1–9 的手感。

### 4.3 机制候选池

按「发生在哪个环节」分类，方便拼方案。

**咬钩阶段**

| 机制 | 玩法 | 提示 / 应对 |
|---|---|---|
| 假咬钩 | 浮漂偶尔只沉一半，这时按就空竿 | 假咬钩浮漂只沉一半、没有 !；真咬钩照旧出 ! |
| 抢食 | 两条鱼同时游向钩子，先咬的那条才算 | 看谁先到，纯观赏，几乎没难度（偏弱） |

**搏斗阶段**

| 机制 | 玩法 | 提示 / 应对 |
|---|---|---|
| 海流 | 张力条上有一段会移动的「顺流区」，张力在区内收线快一倍，区外慢 | 张力条上一段亮色区间，不遮画面 |
| 鲨鱼抢鱼 | 拉鱼超过一定时间，鲨鱼鳍从远处游来，到了就把鱼抢走（算跑鱼，不扣心） | 鱼鳍从屏幕边缘游近，越近越快；逼你冒险快收 |
| 假动作 | 鱼的冲刺预警之后，有时并不冲 | 鱼真冲时身上闪红光；松早了只是少收一点 |
| 打雷 | 偶尔落雷，雷落下前 1 秒顶部出现闪电图标，落下时如果还按着，张力暴涨 | 顶部大图标 + 轻微白闪（不晃屏）；松手就躲开 |
| 双钩 | 有时一次钓到两条，张力翻倍，钓上来两份奖励 | 鱼头上显示「×2」；风险换奖励 |
| 潜底 | 鱼偶尔往下钻，钻的时候收线无效 | 鱼身下冒气泡；等它停 |

**海怪**

| 机制 | 玩法 |
|---|---|
| 狂暴 | 海怪被拉过一半后进入狂暴：冲刺更频繁、身体变红 |
| 多一招 | 每只海怪多一个动作（工作量大：9 只各做一个） |

**整局**

| 机制 | 玩法 |
|---|---|
| 少心 / 不送护盾 | 只有 2 颗心，续关不送护盾（现有规则） |
| 悬赏鱼 | 每片海指定一种鱼，要钓到它才能叫海怪（看运气，可能拖节奏） |
| 海上事件 | 每片海随机发生一个事件（鲨鱼、雷雨、海流、鱼潮……），海况越高同时发生的越多 |

**「夜海」的替代做法**：如果保留夜海的氛围，只做轻微的蓝色色调（约 15%），鱼身和浮漂加亮边，不降低可读性；规则改成「夜里鱼冲刺更突然（预警更短）」。或者直接拿掉夜海，换成上面不影响画面的机制。

### 4.4 组合方案

**方案 A · 天气五级**：每级一种天气或海况，主题最直观。

| 级 | 名字 | 机制 | 顺带数值 |
|---|---|---|---|
| 1 | 风浪 | 假咬钩 | 咬钩时间更短 |
| 2 | 海流 | 张力条顺流区 | 鱼更有劲 |
| 3 | 鲨鱼出没 | 鲨鱼抢鱼；稀有鱼出现 | 海怪更耐打 |
| 4 | 雷雨 | 打雷要松手 | 鱼线更脆 |
| 5 | 怒海 | 海怪狂暴；只有 2 颗心，不送护盾 | 每片海多钓 1 条 |

**方案 B · 鱼更聪明**：不加环境效果，画面完全不变，难度全来自鱼的行为。

| 级 | 名字 | 机制 |
|---|---|---|
| 1 | 机灵 | 假咬钩 |
| 2 | 狡猾 | 假动作冲刺 |
| 3 | 成群 | 双钩（风险换奖励）；稀有鱼出现 |
| 4 | 顽强 | 潜底 |
| 5 | 霸主 | 海怪狂暴；只有 2 颗心，不送护盾 |

**方案 C · 海上事件**：每片海随机抽事件，每局都不一样，重玩性最好。

| 级 | 规则 |
|---|---|
| 1 | 每片海随机 1 个温和事件（海流、鱼潮） |
| 2 | 事件池加入鲨鱼、打雷 |
| 3 | 每片海 2 个事件同时发生；稀有鱼出现 |
| 4 | 事件更频繁、更强 |
| 5 | 海怪狂暴；只有 2 颗心，不送护盾 |

代价：随机性大，难度波动大，平衡和测试工作量最大。

**我的倾向**：方案 A。主题最清楚、每级一眼能看出区别，而且不碰画面亮度；方案 C 的「事件」可以留到无尽深海里用，给深潜增加变化。

## 5. 海怪宝物（海况局特有，讨论中）

### 5.1 已定

- 只在海况 1～5 的局里出现；打败每片海的海怪后，从 3 件里选 1 件。
- 只在本局有效，下潜后继续带着。
- HUD 角落一排小图标显示本局宝物。

### 5.2 候选（约 12～15 件）

**通用**

| 宝物 | 效果 |
|---|---|
| 双钩 | 每片海少钓 1 条就能叫海怪 |
| 回春海草 | 每到一片新海回 1 颗心 |
| 韧丝 | 断线时一半几率不掉心 |
| 暴击连锁 | 暴击后下一下必定暴击 |
| 雷鳗电池 | 放电间隔减半 |
| 贪婪钱袋 | 金币 +60%，但鱼更有劲 |
| 赌徒骰子 | 闪光几率翻倍，但心上限 -1 |
| 疯狂收线 | 收线快 50%，但张力涨得更快 |

**化害为利**（只在对应规则生效时出现）

| 宝物 | 对应规则 | 效果 |
|---|---|---|
| 避雷针 | 打雷 | 躲开的雷劈到鱼身上，麻痹它一下 |
| 驱鲨哨 | 鲨鱼 | 鲨鱼一半几率被吓跑，掉下一笔金币 |
| 夜光鱼饵 | （夜海 / 视方案） | 稀有鱼出现率翻倍 |
| 顺流桨 | 海流 | 顺流区变宽 |

注意：「金币类」宝物会推高排行榜分数，数值要先跑机器人看金币曲线再定。
